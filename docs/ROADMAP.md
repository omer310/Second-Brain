# Roadmap

This document tracks accepted work that the team still intends to build. It is not a history of shipped work; see [CHANGELOG.md](CHANGELOG.md) for that.

## Now

- [ ] **First live review prep and scorecard** — prove review prep is worth trusting before anything runs on its own.
  - Done when: review prep has run on the 20 practice PRs using the pull request as it stood before its first human review, and a scorecard shows catches, misses, and false alarms against each answer key.
- [ ] **Review prep lands in Notion on its own** — the first piece that runs around the clock.
  - Done when: a 15-minute check on Railway finds new pull requests from the pilot roster, writes review prep to Notion, records what it wrote, and never duplicates on re-runs.
  - Depends on: a Notion integration token and the pilot workspace.

## Next

- [ ] **Context that remembers** — once the app keeps its own records, later reviews in a codebase the lead has already seen explain only what's new instead of repeating the project background.
  - Done when: a second review in the same repository gives a shorter context that points at what differs from the earlier review.
- [ ] **CodePath-owned accounts** — Railway, the Anthropic key, the GitHub app, and Notion move to CodePath before any real fellow data. See [the decision](DECISIONS.md#pilot-on-the-leads-railway-plan-production-on-codepath-accounts--2026-09-27).
  - Done when: nothing runs on personal accounts, and CodePath has approved data use.
- [ ] **Foundations checks by Oct 19** — weekly contact, reflections answered within 48 hours, quiet fellows flagged by day 5 with a drafted P2, the Today list, the safety net, and the escalation log.
  - Depends on: the reflections source (ask Kelly or the Commons team) and a one-tap contact log until Slack is approved.
- [ ] **Basecamp pieces by Nov 2** — calibration notes, debrief capture, pre-briefs, the Calendly calendar source, and supervisor update drafts.
- [ ] **Fellows at hosts by Nov 9** — the read-only GitHub app on host repositories, live pull request intake, 24-hour timers for first pieces of work, and the Friday roll call, patterns, and weekly brief.

## Later

- [ ] **Zoom transcripts to drafted debriefs** — after CodePath approval and each fellow's written opt-in. See [the decision](DECISIONS.md#recording-11s--2026-09-27).
- [ ] **Slack signals** — contact and quiet-fellow signals from the fellow community, after workspace approval.
- [ ] **Milestone check-in packs** — Day-30, 60, 90, and 120 packs with the 4Ds self-assessment, competency read, supervisor input, and next-period plan.
- [ ] **End-of-plan artifacts** — host AI training debriefs, the supervisor test, and the portfolio handoff doc.
